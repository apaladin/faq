Inject into your Shopify theme

Host soulara-widget.js + soulara-catalog.json anywhere (or upload the js to Shopify: Content → Files), then in Online Store → Themes → Edit code → layout/theme.liquid, add before </body>:

<script src="https://YOUR-HOST/soulara-widget.js" data-openai-key="sk-..." defer></script>

⚠️ A key in the script tag is visible to every visitor. Only do this on an unpublished preview theme, with a low spending limit on the key — and rotate the key afterwards. When the widget runs on soulara.com.au it automatically uses your live product feed instead of the snapshot.
